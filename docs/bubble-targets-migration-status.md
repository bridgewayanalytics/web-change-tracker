# Bubble Targets Migration — Status Snapshot

**As of:** 2026-11-23
**Snapshot data:** `docs/bubble-target-state-snapshot.json` (deterministic current state, 29 targets × resolved Bubble _id + URL)

## Goal

Move the 29 tracked-URL list out of `targets.json` (checked into this repo) and
onto the Bubble `organization` records (where each committee's URL lives in the
`URL` field of its org). End state: the pipeline reads tracked URLs from Bubble
via `bubble/client.py:list_all()` instead of the bundled JSON file. The
`targets.json` file either gets deleted or becomes a fallback cache.

      orgs = bubble_client.list_all("organization", constraints=SPACE_CONSTRAINT)

## Known constraints

- Bubble Data API `limit` hard-capped at 100 per page — pagination mandatory.
  `bubble/client.py:list_all()` already handles this via `remaining <= 0`.
- Bubble `/obj/organization` **strictly rejects writes to undefined fields** —
  confirmed when `tracked_url` returned `HTTP 400 Unrecognized field`. Writes
  must target fields defined in the Data Type editor. The existing `URL` field
  is the one we use.
- The `space_id` for content lives at
  `1768998437948x865417918648382000`. All org records use this space.
- Two separate "Other" nodes exist in the tree:
  - `Other` at Level 2 (top-level sibling of `NAIC`)
  - `NAIC - Other` at Level 3 (child of `NAIC`)
  Neither currently holds any of our tracked targets — Newsroom and Resource
  Center are direct children of `NAIC` (parallel to Capital Markets Bureau).
